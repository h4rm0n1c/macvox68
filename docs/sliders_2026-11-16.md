# Slider repairs — November 16, 2026

## Behavior

Horizontal track clicks jump to the pointer and continue tracking while held.
Thumb drags retain native Control Manager tracking, including the original grab
offset. Numeric labels repaint while the mouse remains down.

Volume is 0–100% linear amplitude, rate 0.50–2.00 times the channel's initial
words-per-minute rate, and pitch −12 to +12 semitones relative to its initial
pitch. Settings apply to the next editor utterance in either Clean or HL VOX
mode. Repeated utterances do not compound rate or pitch. Settings are not saved
between launches and do not change an utterance already playing.

## Classic API details

The Appearance SDK (macos7-corpus 162) documents slider proc 48 and live variant
bit 1: the live CDEF changes the value before calling the action function.
An invalid rectangle alone does not redraw during blocking TrackControl. Our
Pascal ControlActionUPP paints the label immediately, preserving port and colors.
We check Gestalt 'appr' before creating these controls. Without Appearance the
sliders are unavailable and speech uses defaults; this is not a stock System 7
slider fallback or a completed audit of other Appearance dependencies.

The guest's CDEF only reports thumb hits. ui_slider_track handles the frame
before generic FindControl dispatch. It measures the CDEF thumb centers at the
minimum and maximum using TestControl, then interpolates track clicks between
those centers. GetControlRegion is declared in our headers but unavailable in
the classic 68k link library. This helper supports the application's horizontal,
fixed-range sliders; a vertical or dynamically resized control needs more work.
GetMouse already returns local coordinates: do not GlobalToLocal it again.
Native thumb drags still use TrackControl (corpus 25297).

Speech Manager volume is Fixed 0..1, rate is Fixed words per minute, and pitch
uses semitone units rather than a percentage of MIDI note number (corpus 23628,
23668, 23670). Channel defaults are queried once per new channel. Configuration
errors dispose the channel before allocating its asynchronous text buffer.
The synthesizer may adjust requested pitch (explicitly allowed by 23670).

## Verification

The production Retro68 application/disk builds. Host speech/network contract
checks pass, including exact settings conversion, invalid ranges, repeated
utterances and configuration-failure ownership under sanitizers.

The workspace tools/check_macvox_sliders.py uses oldmac-basilisk MCP against the
instrumented application. It checks both ends of all tracks, native thumb drags,
screenshots captured while held, track clicks after moving the window, and eight
speech-setting combinations across Clean and HL VOX. It reads the actual Speech
Manager settings and command error results. Rate and volume are checked to one
Fixed least-significant bit; pitch allows one semitone for this synth’s coarse low-pitch quantization.
A requested +7 reads back +6.984375; −12 reads back −11.4375 on this guest.
The host check, rather than this tolerance, verifies the exact requested value.

The lab adapter now reports rate/pitch/volume and accepts signed control values;
negative semitone offsets use a signed Mac short over unsigned bridge words.
The MCP drag_preview operation captures before releasing the mouse. These lab
changes live under OldMacStuff/tools, outside this application repository.

Testing uses virtual audio with the USB dongle and browser viewer disabled.
Settings inspection does not replace listening, establish acceptable VOX cadence,
or prove compatibility with other synthesizers. Keyboard slider navigation,
presets, preference persistence and broader focus/activation audits remain work.
