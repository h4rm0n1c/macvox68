# VOX cadence: reference boundary placement — November 16, 2026

Both local Windows references were read without modification:

- NetTTS: /home/harri/flextalk/prefix32/drive_c/nettts/src/vox_parser.cpp
- VoxTalk: /home/harri/voxtalk/src/vox_parser.cpp

The C port had moved generic token append and punctuation handling before the
heavy-word gates. The references run those gates first. This placed breaks after
words instead of before them, and punctuation could skip weight processing.
For example, `all personnel. BR` now becomes `all BR personnel.`; `is departing.
BR` now becomes `is BR departing.`. These are changes in phrase grouping, not
arbitrary silence or rate adjustments.

Tidy now removes consecutive BR tokens and spaces before punctuation, as the
references do. The final-silence marker is separated from the preceding text
rather than adding a leading space before the whole sentence. Time expansion
retains two minute digits and recognizes four-digit HH00 hours (the port tested
five digits). Blank preprocessing returns an owned empty string, distinguishing
valid empty input from failure; empty formatting remains safe in both modes.
